# MyMac 需求整理文档

## 需求总览

MyMac 是一款 macOS 电脑管家软件，定位「轻量、快速、原生」，通过状态栏快速观察系统状态，随时打开主窗口进行管理操作。

## 已实现功能

### 1. 系统资源监控
- 实时展示 CPU、内存、磁盘、网络等资源占用情况（2 秒刷新）。

### 2. 应用快速卸载
- 列出可卸载应用（含版本、占用空间），扫描常见关联文件，由用户勾选后统一移入废纸篓。

### 3. 启动项管理
- 查看登录启动项，支持搜索、Finder 定位、启用 / 禁用及删除用户级启动项。

### 4. 状态栏入口
- 菜单栏常驻图标，动态展示资源占用；点击图标或菜单项唤起主窗口；关闭主窗口时隐藏 Dock 图标但保持状态栏运行。

### 5. 状态栏显示配置
- 可配置状态栏是否显示 Logo、CPU、内存、磁盘、网络信息，配置持久化到本地。

## 待开发功能

### 6. 粘贴板管理（本阶段开发）
- **目的**：快速追溯粘贴板历史记录，支持管理、清空、快速选择复制粘贴；在状态栏中提供快速选中历史复制数据的能力。

#### 功能需求
1. **历史记录监听**
   - 应用运行期间后台持续监听系统剪贴板，捕获复制/剪切产生的文本内容；
   - 相同内容连续出现时只保留最新一条（去重）；
   - 历史记录数量设上限（默认 200 条），超出后淘汰最旧记录；
   - 应用重启后历史记录仍然保留（本地持久化）。
2. **历史记录管理（主窗口「粘贴板」页面）**
   - 列表展示历史记录：内容预览（长文本截断）、复制时间、内容长度；
   - 支持按关键字搜索过滤；
   - 支持删除单条记录；
   - 支持一键清空全部记录；
   - 点击任意记录可复制回系统剪贴板，并置顶该记录。
3. **状态栏快速操作**
   - 状态栏菜单中提供「粘贴板历史」子菜单，展示最近若干条记录（默认 10 条）；
   - 点击子菜单中的记录直接复制到系统剪贴板；
   - 状态栏菜单提供「清空粘贴板历史」入口。
4. **数据存储**
   - 历史记录存储于 `~/Library/Application Support/MyMac/clipboard_history.json`；
   - 监听线程捕获新记录时增量保存，避免频繁全量写入。

#### 技术方案
- 剪贴板读写：Rust crate `arboard`（macOS 原生 NSPasteboard）；
- 监听方式：后台线程定时轮询剪贴板文本内容，与最近一次记录比对，变化则入库；
- 状态栏：Tauri 菜单动态重建「粘贴板历史」子菜单，菜单事件中写回剪贴板；
- 前后端交互：Tauri command 暴露查询 / 删除 / 清空 / 复制接口。

#### 验收标准
- 复制文本后，主窗口「粘贴板」页面与状态栏菜单均能出现对应记录；
- 点击记录可复制回剪贴板（粘贴验证内容一致）；
- 删除单条、清空全部立即生效且持久化；
- 重启应用后历史记录仍然存在；
- `cargo check` 与前端 `yarn build` 通过。
