# MyMac 需求整理文档

## 需求总览

MyMac 是一款 macOS 电脑管家软件，定位「轻量、快速、原生」，通过状态栏快速观察系统状态，随时打开主窗口进行管理操作。

## 已实现功能

### 1. 系统资源监控
- 实时展示 CPU、内存、磁盘、网络等资源占用情况（2 秒刷新）。

### 2. 应用快速卸载
- 列出可卸载应用（含版本、占用空间），扫描常见关联文件，由用户勾选后统一移入废纸篓。

### 3. 启动项管理
- 查看登录启动项，支持搜索、Finder 定位、启用 / 禁用及删除用户级启动项。

### 4. 状态栏入口
- 菜单栏常驻图标，动态展示资源占用；点击图标或菜单项唤起主窗口；关闭主窗口时隐藏 Dock 图标但保持状态栏运行。

### 5. 状态栏显示配置
- 可配置状态栏是否显示 Logo、CPU、内存、磁盘、网络信息，配置持久化到本地。

## 待开发功能

### 6. 粘贴板管理（本阶段开发）
- **目的**：快速追溯粘贴板历史记录，支持管理、清空、快速选择复制粘贴；在状态栏中提供快速选中历史复制数据的能力。

#### 功能需求
1. **历史记录监听**
   - 应用运行期间后台持续监听系统剪贴板，捕获复制/剪切产生的文本和图片内容；
   - 优先记录文本内容；仅当剪贴板无文本内容时记录图片；
   - 相同内容连续出现时只保留最新一条（去重）；
   - 历史记录数量设上限（默认 200 条），超出后淘汰最旧记录（对应图片文件同步删除）；
   - 应用重启后历史记录仍然保留（文本持久化到本地 JSON，图片持久化到本地 PNG 文件）。
2. **历史记录管理（主窗口「粘贴板」页面）**
   - 列表展示历史记录：文本记录显示内容预览，图片记录显示缩略图；均显示复制时间；
   - 支持按关键字搜索过滤；
   - 支持删除单条记录（图片记录同时清理磁盘文件）；
   - 支持一键清空全部记录（同时清理图片目录）；
   - 点击文本记录可复制回系统剪贴板并置顶；点击图片记录可复制图片到剪贴板并置顶；支持查看原图。
3. **状态栏快速操作**
   - 状态栏菜单中提供「粘贴板历史」子菜单，展示最近若干条记录（默认 10 条）；
   - 文本记录显示内容预览，图片记录显示「图片」及尺寸；
   - 点击子菜单中的记录直接复制到系统剪贴板；
   - 状态栏菜单提供「清空粘贴板历史」入口。
4. **数据存储**
   - 文本与元数据存储于 `~/Library/Application Support/MyMac/clipboard_history.json`；
   - 图片原图存储于 `~/Library/Application Support/MyMac/clipboard_images/<id>.png`（RGBA8）；
   - 图片缩略图存储于 `~/Library/Application Support/MyMac/clipboard_images/<id>_thumb.png`（最大边 256px）；
   - 监听线程捕获新记录时增量保存。

#### 技术方案
- 剪贴板读写：Rust crate `arboard`（macOS 原生 NSPasteboard，默认启用 image-data feature）；
- 图片处理：Rust crate `image`（PNG 编解码、缩略图生成）；
- 监听方式：后台线程每 500 毫秒仅检查 macOS 剪贴板变化编号；应用启动时不读取剪贴板，也不常驻持有读取对象；本地内容变化稳定后临时读取一次；来自其他设备的内容先等待 3 秒，让用户实际粘贴优先，期间未发生新变化时再单次读取并纳入历史；读取时优先文本，无文本时读取图片数据（RGBA8）；
- 去重策略：文本以内容比较，图片以宽高 + 字节内容哈希比较；
- 状态栏：Tauri 菜单动态重建「粘贴板历史」子菜单，菜单事件中写回剪贴板；
- 前后端交互：Tauri command 暴露查询 / 删除 / 清空 / 复制 / 查看原图接口。

#### 验收标准
- 复制文本后，主窗口「粘贴板」页面与状态栏菜单均能出现对应记录；
- 点击记录可复制回剪贴板（粘贴验证内容一致）；
- 删除单条、清空全部立即生效且持久化；
- 重启应用后历史记录仍然存在；
- `cargo check` 与前端 `yarn build` 通过。

### 7. 2FA 验证码生成器（本阶段开发）
- **目的**：集中管理常用 TOTP 两步验证码，并通过状态栏快速复制当前验证码。

#### 功能需求
1. **账户管理**
   - 主窗口新增「2FA 验证码」页面；
   - 支持通过 Base32 密钥或标准 `otpauth://totp/...` 链接添加账户；
   - 支持直接调用 macOS 区域截图或读取剪贴板截图，识别其中的二维码并自动填入账户信息；
   - 账户包含名称、发行方、密钥、位数和刷新周期；
   - 支持删除账户，账户数据在应用重启后保留。
2. **验证码生成与复制**
   - 按 TOTP 标准生成当前验证码，默认使用 SHA-1、6 位数字、30 秒周期；
   - 页面实时展示验证码和本周期剩余时间；
   - 点击验证码或复制按钮可写入系统剪贴板；
   - 应用主动复制的验证码不写入粘贴板历史。
3. **状态栏快速操作**
   - 状态栏新增「2FA 验证码」子菜单；
   - 子菜单展示各账户名称及当前验证码，点击后直接复制；
   - 提供「管理 2FA 验证码」入口，点击后打开主窗口对应页面；
   - 验证码随时间自动更新。
4. **数据存储**
   - 账户名称、发行方、位数和周期等基本信息存储于 `~/.mymac/totp_accounts.json`，普通应用卸载后仍可恢复；
   - Base32 密钥集中保存在 macOS 钥匙串的单一 2FA 密钥库项目中，不写入 JSON，也不返回给前端列表；应用启动时最多读取一次钥匙串；
   - 自动迁移旧版逐账户钥匙串项目，迁移成功后删除旧项目；
   - 启动时自动迁移 `~/Library/Application Support/MyMac/totp_accounts.json` 中的现有账户，迁移成功后删除旧的明文文件；
   - `~/.mymac` 目录仅允许当前用户访问，元数据文件仅允许当前用户读写。

#### 验收标准
- 使用已知 Base32 密钥添加账户后，可生成符合 TOTP 标准的验证码；
- 可解析标准 `otpauth://totp/发行方:账户` 链接；
- 主窗口验证码、倒计时和复制功能正常；
- 状态栏可查看并快速复制各账户验证码；
- 删除账户和重启后的持久化结果正确；
- `cargo check` 与前端 `yarn build` 通过。

### 8. Homebrew 管理（本阶段开发）
- **目的**：在 MyMac 内完成 Homebrew 的准备和日常软件管理，同时覆盖命令行软件与图形应用。

#### 功能需求
1. **安装状态与初始安装**
   - 自动识别 Apple 芯片和 Intel Mac 上的标准 Homebrew 安装位置；
   - 未安装时展示说明，并在系统终端中启动 Homebrew 官方安装流程，保留管理员授权和安装输出供用户确认；
   - 安装后可刷新状态，展示版本与安装路径。
2. **软件源管理**
   - 支持官方源、清华大学镜像和中科大镜像；
   - 切换后对 MyMac 发起的 Homebrew 操作立即生效，并持久保存选择；
   - 同步调整 Homebrew 主仓库及已存在的 core、cask 仓库地址；切回官方源时恢复官方地址。
3. **软件管理**
   - 支持按名称搜索 formula（命令行软件）和 cask（图形应用）；
   - 展示已安装软件、版本、类型和是否存在更新；
   - 第三方 tap 中尚未被 Homebrew 信任的软件需要单独标注为“未信任”，该软件读取失败不能阻断其他已安装软件和页面基础信息的展示；
   - 支持安装搜索结果、卸载已安装软件、更新单个软件；
   - 支持刷新软件清单，以及更新 Homebrew 索引并更新全部过期软件。
4. **交互与安全**
   - 操作期间禁用重复提交并展示当前动作；
   - 操作完成后刷新数据并明确显示成功或失败信息；
   - 软件名称和类型必须经过后端校验，所有 Homebrew 参数均以独立参数传递，不拼接用户输入执行。

#### 验收标准
- 未安装 Homebrew 时能识别状态并从页面启动官方安装流程；
- 已安装时能正确展示版本、路径和当前源；
- 三种软件源可切换并在应用重启后保留；
- 能同时搜索 formula 和 cask，并安装搜索结果；
- 能列出、卸载和更新已安装软件，也能执行全部更新；
- 失败信息可见，操作后列表状态正确刷新；
- 存在未信任的第三方 cask 时，该软件有明确标注，其余已安装软件和页面信息仍可正常展示；
- `cargo check` 与前端 `yarn build` 通过。
